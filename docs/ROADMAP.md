# Milestone roadmap

- **C0 — cloud foundation:** reproducible TypeScript/Three.js/Vite build; underwater scene; module boundaries; deterministic state; automated checks; Blender/export feasibility. Completed with limitations in PROJECT_STATE.md.
- **C1 — largemouth bass modeling:** authorized on 2026-10-12; first candidate rejected by the owner, photographic rework in progress on the existing branch and draft PR #2. Preserve the saved body/fin work and reconstruct the jaw/head against actual photographic references. Deliver seven matched anatomical views, an additional open three-quarter view, temporary jaw-articulation evidence, geometry/export validation and isolated Three.js loading evidence. Higher geometry budgets require explicit approval. Stop for the user's visual approval; automated passes do not constitute visual acceptance. Physical iPhone performance remains to be measured.
- **C2 — animation development (requires C1 visual approval and further authorization):** deform rig, weighting, baked swimming clips and loop/deformation review. Simulation and habitat interaction follow with approved assets: refine species steering, feeding and progression; integrate interaction and save storage/migrations.
- **C3 — showroom and performance:** species comparison, habitat variations, LODs, texture compression and measured device quality tiers.
- **C4 — release hardening:** device/browser matrix, accessibility checks, thermal/memory endurance, recovery, distribution and release automation.

Future milestones are proposals, not authorization. C1 stops at its visual approval gate. The user's C1 request supersedes the earlier roadmap's placement of swimming clips in C1.

The current C1 candidate adapts the owner-supplied DigitalLife3D Model 67A for confirmed personal, noncommercial use. Its original source and previous C1 checkpoints are preserved. The static export, matched seven-view evidence, bounded jaw test and independent Astra review are documented separately; no source swimming action is adopted and no gameplay integration is added.
